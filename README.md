# Antigravity 工作区联动 Wallpaper Engine 更换动态壁纸

把 Wallpaper Engine 的订阅壁纸用作 Antigravity 工作区背景。可以跟随桌面，也可以给工作区单独选一张。

**适用环境** · Windows · Antigravity 桌面版 2.35.2 · Wallpaper Engine

- **独立选图**　从订阅图库挑选工作区壁纸，桌面可以用另一张。
- **动态播放**　视频壁纸静音循环播放。场景和网页壁纸显示项目预览，有 GIF 预览时也能动起来。
- **随机轮换**　打开「随机播放」，工作区可见时每分钟换一张。
- **调整可见度**　滑杆往右，壁纸更清晰；往左，文字更突出。每张壁纸单独记住设置。

## 在另一台电脑上使用

1. 在仓库首页点击 **Code → Download ZIP**，然后解压。
2. 找到包含 SKILL.md 的文件夹，将它重命名为 **antigravity-wallpaper-engine**。
3. 将这个文件夹放进下面的目录。可以把路径粘贴到 Windows 文件资源管理器的地址栏，若目录尚不存在，先创建它。

    `%USERPROFILE%\.codex\skills\`

4. 打开一个新的 Codex 聊天，复制并发送下面这句话。

    > 使用 $antigravity-wallpaper-engine 设置我的 Antigravity 工作区壁纸。

Codex 会根据这台电脑的实际安装位置查找 Steam 库和 Antigravity。安装完成后，点击工作区右下角的 **「选择壁纸」**，就能换图或调整可见度。
