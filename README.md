# Antigravity-Skills
【使用 Antigravity-wallpaper-engine 联动设置我的工作区动态壁纸/静态】
在另一台 Windows 电脑上使用：下载并解压完整 Skill，将 antigravity-wallpaper-engine 文件夹放入 %USERPROFILE%\.codex\skills\，然后在新的 Codex 聊天中输入 「使用 $antigravity-wallpaper-engine 设置我的工作区壁纸」。Skill 会指导 Codex 查找那台电脑的 Steam 库和 Antigravity 安装位置。#
（各位大佬可以根据自己的喜好用codex或者Antigravity进行安装和设置，进一步优化大家看自己喜好吧！哈哈啊哈）
